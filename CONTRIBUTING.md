# Contributing

- **Submit a tool:** use the *Submit an agent* issue form.
- **Fix or update an entry:** edit `data/agents.json`, run `python3 scripts/build_readme.py`, and open a pull request. Do not edit the tables in README.md by hand.
- **Write descriptions in your own words.** Do not paste from the project's README or marketing copy.
- **Keep it factual.** No ranking claims unless sourced, no promotional language.
- **Removal requests:** project authors can ask for removal of their entry at any time via an issue.
